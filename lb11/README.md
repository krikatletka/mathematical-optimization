# Лабораторна робота № 11 мовою C++

У проєкті є дві окремі консольні програми за двома частинами презентації.

Використано основний контрольний приклад зі слайдів:

```text
F(x1,x2) = 2*x1^2 + 3*x2^2 + x1*x2
x(0) = (5;-3)
g1(x) = 4-x1-x2 <= 0
```

## Файли

- `optimization.hpp`, `optimization.cpp` — вектори, обмеження, Свенн, золотий переріз,
  Флетчер—Рівс, сферичний градієнтний метод, зовнішній штраф і логарифмічний бар'єр;
- `part1.cpp` — усі завдання частини 1;
- `part2.cpp` — усі вісім завдань частини 2;
- `tests.cpp` — контрольні автоматичні тести;
- `run_all.bat` — складання і запуск у Windows через MinGW g++;
- `run_msvc.bat` — складання компілятором Visual Studio;
- `CMakeLists.txt` — складання через CMake.

## Швидкий запуск у Windows

Якщо встановлений `g++`, двічі натисніть `run_all.bat`.

Або в PowerShell:

```powershell
g++ -std=c++17 -O2 optimization.cpp tests.cpp -o lr11_tests.exe
g++ -std=c++17 -O2 optimization.cpp part1.cpp -o lr11_part1.exe
g++ -std=c++17 -O2 optimization.cpp part2.cpp -o lr11_part2.exe
./lr11_tests.exe
./lr11_part1.exe
./lr11_part2.exe
```

## Запуск у Visual Studio

Створіть порожній консольний проєкт C++17 і додайте `optimization.cpp` разом тільки з одним
файлом запуску: `part1.cpp`, `part2.cpp` або `tests.cpp`. Не додавайте всі три файли з `main`
до одного проєкту одночасно.

Або відкрийте **Developer Command Prompt for Visual Studio** і запустіть `run_msvc.bat`.

Програми створюють CSV у папці `outputs`. За ними пізніше можна побудувати потрібні графіки.

> Примітка. Таблиця обмежень особистих варіантів ЛР 11 у наданих PDF відсутня. Тому код
> налаштовано на повністю перевірюваний основний приклад із презентацій. Функції та
> обмеження винесено окремо, щоб їх можна було замінити без переписування алгоритмів.
